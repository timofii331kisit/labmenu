# labmenu
labmenu is a C-based console utility for Windows. Using the WinAPI, it calculates file sizes, displays memory usage and available drive letters, generates statistics on file sizes, captures a snapshot of running processes in CSV format, and maintains a launch counter with file locking. It can operate in a menu-driven mode or via the command line (e.g., `labmenu lab3 1024`). It was developed as a coursework project for a systems programming course at college.
