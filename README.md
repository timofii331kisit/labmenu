# labmenu
labmenu - консольная утилита для Windows на C. Через WinAPI она считает размеры файлов, показывает загрузку памяти и свободные буквы дисков, строит статистику по размерам файлов, делает снимок процессов в CSV и ведёт счётчик запусков с блокировкой файла. Работает в режиме меню или из командной строки: labmenu lab3 1024.
